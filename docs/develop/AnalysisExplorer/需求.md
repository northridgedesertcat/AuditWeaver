# Agent 功能需求

## 1. 功能介绍

开发一个 **Analysis Explorer Agent**。

用户可以在网页中的 Agent 页面输入自然语言问题，Agent 根据用户的问题调用对应 Skill 查询 Elasticsearch 中的数据，然后分析查询结果并回答用户。

---

## 2. 核心功能

### 2.1 用户对话

用户可以输入自然语言问题，例如：

> `192.168.1.100 最近有什么危险行为？`

Agent 理解用户的问题，并决定需要查询哪些数据。

---

### 2.2 查询日志

Agent 可以通过 Skill 查询 Elasticsearch 中的原始日志。

例如：

> 查询某个 IP 最近的访问日志。

---

### 2.3 查询分析结果

Agent 可以通过 Skill 查询 **Log Analysis Agent 产生的分析结果**。

例如：

> 查询某个 IP 是否被识别为暴力破解、异常访问等。

---

### 2.4 分析并回答

Agent 获取 Elasticsearch 数据后，对数据进行分析和总结，然后向用户返回自然语言结果。

例如：

> 该 IP 最近 24 小时产生了大量登录失败请求，并被日志分析 Agent 判断为疑似暴力破解，风险等级为 High。

---

# 3. 一个完整案例

用户：

> `192.168.1.100 最近有什么危险行为？`

Agent：

```text
用户问题
   ↓
Analysis Explorer Agent
   ↓
调用 QueryIPLogs Skill
   ↓
查询 ES
   ↓
调用 QueryAnalysisResults Skill
   ↓
查询 ES
   ↓
分析结果
   ↓
返回用户
```

---

# 4. Skill

第一版只做三个：

| Skill                  | 功能          |
| ---------------------- | ----------- |
| `QueryIPLogs`          | 查询指定 IP 的日志 |
| `QueryAnalysisResults` | 查询日志分析结果    |
| `QuerySecurityEvents`  | 查询最近的安全事件   |

---

# 5. 技术栈

```text
前端：React
后端：FastAPI
Agent：LangChain / LangGraph
Skill：MCP
LLM：API 模型
数据库：Elasticsearch
```
单独用LangChain和LangGraph封装一个agent模块。后端调用这些api接口。agent模块中实现模型相关的内容。后端仅仅调用。
