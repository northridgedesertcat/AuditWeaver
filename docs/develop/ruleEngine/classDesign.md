# Class Design

## Class: AnalysisPipeline

### Purpose
Coordinate the entire log analysis workflow.

### Responsibilities
- Coordinate the execution order of components.
- Pass data between modules.
- Handle pipeline exceptions.

### Collaborates with
- KafkaConsumer
- Preprocessor
- RuleEngine


---

## Class: KafkaConsumer

### Purpose
Consume log messages from Kafka.

### State
- Kafka connection
- Topic configuration
- Consumer configuration

### Methods
- consume()

### Input
Kafka Message

### Output
RawLog

### Responsibilities
- Establish Kafka connection.
- Consume messages from specified topics.
- Forward raw log data to AnalysisPipeline.

### Collaborates with
- AnalysisPipeline


---

# Class: Preprocessor

### Purpose
Transform raw logs into normalized log messages.

### Responsibilities
- Decode encoded content.
- Validate required fields.
- Extract required log fields.
- Normalize log structure.

### Input
RawLog

### Output
LogMessage

### Collaborates with
- Decoder
- StructureNormalizer


---

## Class: Decoder

### Purpose
Decode encoded content from raw log fields.

### Responsibilities
- URL decode.
- Double URL decode.
- HTML entity decode.
- Unicode escape decode.

### Input
Raw log fields

### Output
Decoded log fields


---

## Class: StructureNormalizer

### Purpose
Convert raw log data into a unified structure.

### Responsibilities
- Check missing required fields.
- Extract required fields.
- Generate standardized LogMessage.

### Input
Decoded log data

### Output
LogMessage


---

# Class: RuleEngine

### Purpose
Execute rule-based detection on normalized logs.

### Responsibilities
- Execute rule matching.
- Collect matched patterns.
- Combine matching results with log context.
- Generate SecurityEvent.

### Input
- LogMessage
- RuleProfile
- RegexPattern

### Output
SecurityEvent

### Collaborates with
- RuleLoader
- RegexMatcher
- EventBuilder


---

## Class: RuleLoader

### Purpose
Load rule configurations from repositories.

### Responsibilities
- Load rule profile YAML files.
- Load regex pattern configurations.
- Provide rule configuration for RuleEngine.

### Input
Rule Profile Repository
Regex Pattern Repository

### Output
- RuleProfile
- RegexPattern



---

## Class: RegexMatcher

### Purpose
Execute regex-based matching.

### Responsibilities
- Match log fields with regex patterns.
- Return matching information.

### Input
- Target field content
- Regex Pattern

### Output
MatchResult


---

## Class: EventBuilder

### Purpose
orgenize a security event generated by the Rule Engine.

this is the export of rule engine.

### Responsibilities
- orgenize the return data.combine the original data and MatchResult.


### Output
- SecurityEvent
Used for:
- Kafka producer


## Class: KafkaProducer
### Purpose
send SecurityEvent to kafka.
